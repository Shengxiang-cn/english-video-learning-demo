# Mobile App Design Workspace

This top-level directory is reserved for app/mobile work only.

Suggested structure:

- `docs/`: app-specific product notes, flows, and design decisions
- `references/`: screenshots, inspiration, and imported visual references
- `prototype/`: interactive prototype files or front-end experiments for app flows
- `handoff/`: implementation-ready specs, copy, tokens, or export artifacts

Recommended rule:

- If a file is only for the desktop web demo, it should not live here.
- If a file is only for the mobile app direction, it should live here.
