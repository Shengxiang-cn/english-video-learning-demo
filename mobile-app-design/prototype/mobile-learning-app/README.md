# Mobile Learning App Prototype

This is the runnable mobile app prototype for the long-video learning MVP.

Scope of this directory:

- iPhone-sized app UI exploration
- transcript highlighting interactions
- AI ask / note / export flows
- app-only front-end experiments

Do not use this directory for desktop web workspace concepts.

Useful commands:

```bash
npm install
npm run dev
npm run build
npm run lint
```
